Please run llm in your local machine, using llama.cpp, Ollama or docker model runner.

To utilize this feature, your local machine must host an LLM that's compatible with the OpenAI API. Please note that Safari may prevent access to http resources from https domains without a valid SSL certificate for your local LLM server.

For using this tool, you might want to try Google Chrome or Firefox instead.

If you are using ollama, set the environment variable to allow cors.
And then start ollama server (port 11434), with below command

On Linux/Mac

export OLLAMA_ORIGINS="[YOUR URL]"
ollama serve

On Windows

setx OLLAMA_ORIGINS "[YOUR URL]"
ollama serve
